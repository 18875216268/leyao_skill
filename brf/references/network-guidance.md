# 网络层自助规划指引（AI 联网自助方案）

> 触发：`brf.py resolve --allow-network` 返回 `reason: network_required`（知识域 K1-K3 与工具域 T1/T2 **均未解决**时）。
> 原则：**BRF 不直接联网执行**——由 AI 按本指引**自助规划**：判断缺口类型 → 多渠道搜索 → 评估候选 → 下载/安装 → 本地验证 → 注册资产或沉淀知识。不是单一联网查询，而是多渠道、多来源的自助方案。

## 一、判断缺口类型（先分类再找）

| 缺口 | 特征 | 找什么 |
|---|---|---|
| 知识类（缺定义/口径/概念） | 问句是「X 是什么/怎么定义」 | 领域权威定义、官方文档、专业词典 |
| 技能类（缺工具/技能/脚本） | 需要「能执行的工具/能力」 | skill 包、脚本、工具库 |
| 数据类（缺数据/指标值） | 需要「具体数值/数据集」 | 开放 API、官方统计、行业报告 |
| 方法类（缺流程/SOP/方法论） | 需要「怎么做才对」 | 方法论文章、论文、行业标准、SOP 库 |

## 二、渠道矩阵（按缺口选渠道）

| 缺口 | 首选渠道 | 补充渠道 | 优先级 |
|---|---|---|---|
| 技能/工具 | **GitHub**（搜 skill/工具/脚本） | **AI 模型官方 skill 市场**、CSDN 技术博客 | 热门源优先（star/下载量/更新） |
| 知识/术语 | **必应 / 百度** | 领域权威站、官方文档、Wikipedia | 权威源优先 |
| 数据 | 官方统计 / 开放 API | 行业报告、数据平台 | 权威源优先 |
| 方法 | 专业博客 / 学术（arXiv） | 行业标准、知名公众号/专栏 | 权威源优先 |

> 关键词提炼：主词 + 领域限定词（如「乐药」「医药」「毛利」）+ 类型词（skill / 脚本 / 数据集）。

## 三、自助规划步骤（AI 执行）

1. **提炼搜索关键词**：主词 + 领域限定 + 类型词，准备 ≥2 组变体；
2. **多渠道搜索**：至少 2 个渠道交叉验证（防单一来源偏差）；
3. **评估候选**：
   - 权威性：官方 / 知名机构 / 大厂 / 高 star 仓库；
   - 热度：star 数、下载量、最近更新、社区讨论；
   - 适配性：语言、依赖、许可协议、是否可本地离线运行；
4. **下载/安装**（**必须 approval**）：只装可信来源；核对来源 URL 与哈希；
5. **本地验证**：冒烟测试（跑通最小用例）确认可用；
6. **注册为 BRF 资产**：按 3 步接入（`examples/README.md`：准备数据/工具 → registry 加资产 → `ask()` 验证）→ 下次同类卡点 T1/T2 直接命中；
7. **沉淀**：获得的新知识（术语/口径/方法）走主 skill supervisor 提案（L1/L2/L3 分级，proposal 审批）→ 写入 semantic 记忆 → 下次 K1 命中。

## 四、安全纪律

- 联网 / 下载 / 安装 / 写记忆 → **一律 approval**（用户确认）；
- 只读为主：外部资源只读；唯一写入 = 主 skill 记忆/缓存（进化沉淀）；
- 来源可追溯：记录 URL / 来源 / 版本（进入 path 与记忆 evidence）；
- 不执行不可信代码：下载的脚本先审查再运行；
- 未找到 / 质量不足 → 返回 unresolved 并转用户确认（不静默假定）。

## 五、闭环

```
网络层触发（K1-K4/T1/T2 均无解）
  → AI 自助规划（分类 → 渠道矩阵 → 步骤 1-7）
  → 获得方案（资产注册 or 知识沉淀）
  → 下次同类卡点：T1（本地工具）或 K1（记忆）直接命中
  → 越用越强（框架自进化）
```

## 六、与 resolve 的衔接

```bash
# 触发网络层引导（需 approval 语义）
python brf.py resolve --problem "<问题>" --allow-network
# 返回：{ "ok": false, "reason": "network_required",
#         "hint": "…自助规划…", "guidance_doc": "references/network-guidance.md" }
```

AI 收到 `network_required` 后：读取本指引 → 按缺口类型与渠道矩阵规划 → 执行（每一步联网/下载/安装先向用户确认）→ 成功后注册资产或沉淀记忆。
