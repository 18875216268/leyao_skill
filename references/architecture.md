## 2. 主链拓扑（五环嵌套 —— 13 执行点全在环上）

```text
主干（门禁式递进：理解门+资源门全开才推进）：
 0 ─→ 1 ─→ 2 ─→ 3a→3b→3c ─→ 4 ─→ 5 ─→ 6 ─→ 7a→7b→7c ─→ 8
请求  工作包  需求   交付物   Task  验证   抽象  能力  执行   执行→四门→交付  复盘
理解  理解    确认    锚定   拆解   依赖   流程  工具  计划   证据 复核       沉淀

五环（每个执行点至少在一个环上 · 本系统是环拓扑，不是流水线）：

环1 理解环（0↔1↔2 六边双向）：语义层0↔材料层1↔需求层2
    意图喂读/材料回馈/材料事实/缺口回馈/意图约束/需求回查；节点四选项（继续/重启本阶段/重启子步骤/回退上游）
环2 规划环（3a↔3b↔3c↔4↔5↔6）：锚定→Task→验证→流程→工具→计划
    规划-资源循环（缺资源边规划边找）+ 再规划（失败/新信息/需求变/资源/依赖阻塞 5 触发）
环3 执行环（7a↔7b↔7c）：执行→四门复核→交付
    四门不过按门回退（交付门→2 补验收 / 计算门→2 补口径 / 数据门→1 重建包 / 证据缺失→7a）
环4 自进化环（8→learn→K1→0 跨 Run）：复盘→learn 沉淀→下次 K1 命中→新任务
    不满信号→跳过早停重解；监督→core→下次准绳；AMD 注入（proactive/reactive）
环5 治理横切环（贯穿任意步）：实时控制/监督/资产导航/思考协议/知识前置/先取后求
    任意执行点可被触发回退或注入——判断前/执行中全程生效

跨环回退（阶段回环 · 回退三要素）：
任意下游发现错误 → 定位（结构检查点=子步骤边界）→ 置信（高置信才回退，防过度纠错）
→ 等待（给足上下文再判断，防过早干预）→ 按根因表映射上游 → 增量重走（上限 2 防死循环）

并行（非串行执行）：BRF 阶段 1/2 并发扇出（线程池）+ resolve 阶段 2 并行
```

## 3. 横切三层（贯穿主链 · 非普通步骤）

```text
3.0 思考协议（判断前 · 横切总则）→ chain-overview「思考协议」
    五步心智（假设→核验→查证→分层→最小确认）‖ 思考预算三档（快判/标准/深度）
3.1 实时控制层（控偏差）→ governance.md「实时控制」
    intent anchor · checkpoint(K0-K10) · 双准绳 · 用户信号→episodic
3.2 自我进化与监督层（促进化）→ memory-and-supervision.md
    learn 沉淀 · consolidate 固化 · 监督跨 Run 评估 · proposal 审批（semantic/core 唯一写入权）
3.3 资产导航层（找资源）→ governance.md「卡点调度」+ chain-overview「外援路径」
    知识→BRF │ 工具→动态发现 │ 能力→注册 │ 方法论→外援分级
```

## 4. 缓存记忆层（五环 · 知识底座）

```text
记忆区：working(Run内) · episodic(不可变) · semantic(确认知识) · core(稳定偏好) · cache(派生)
读写五环：读取环(K1+AMD+FTS5+评分) → 写入环(learn+record) → 固化环(consolidate)
         → 程序环(kind=procedure) → 治理环(cache_governor+监督)
职责边界：记忆区只存储/检索/固化候选，不做判断/审批/评分/驱动
```

## 5. BRF + 云端两库闭环（获取→审查→维护→回流）

```text
┌─ 获取环 ────────────────────────────────────────────┐
│ 阶段1 本地K1(硬早停)                                  │
│ 阶段2 注入库(authority) ‖ 会话库(reference) 并行两路  │
│        → 云智库(leyou 外部源·AI 自主规划)          │
│ 阶段3 网络兜底（仅空结果 · approval）                 │
└──────────┬──────────────────────────────────────────┘
           ↓ 命中内容进交互
┌─ 审查环（learn）─────────────────────────────────────┐
│ 原创→会话库(三层闸+帕累托) │ 借鉴→adopt 回流 value    │
│ 注入库：仅用户显式（authority 纯度）                  │
└──────────┬──────────────────────────────────────────┘
           ↓ submit / inject
┌─ 维护环（云端）─────────────────────────────────────┐
│ hit/adopt/freshness 奖惩 → 排序加权 → 回流获取环      │
└──────────────────────────────────────────────────────┘
```
